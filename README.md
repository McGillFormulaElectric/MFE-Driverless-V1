# MFE-Driverless-V1

Welcome to the McGill Formula Electric Driverless Software repository! In this repository you can find all the required packages to boot and operate an NVIDIA Jetson with the MFE2X car. 

This page is still under construction. Stay tuned!

## Simulation tests

Headless end-to-end tests of the autonomy stack in the EUFS simulator (finish, on-track, cones touched, lap and
speed scoring, batches, videos and load summaries). See [tools/validation/sim_harness/README.md](tools/validation/sim_harness/README.md)
for prerequisites, environment variables and how to run them.
